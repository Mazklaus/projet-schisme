# projet-schisme

Dépôt **privé** de travail. Il ne doit jamais devenir public, et aucun build, aucune vidéo ni aucune capture ne doit en sortir.

Jeu narratif 2.5D à épisodes, pour PC natif, sous Godot 4.7.2. Le squelette du moteur est en place, avec des placeholders seulement. Voir [docs/architecture.md](docs/architecture.md).

- `etude/game-design.md` : étude de game design (Game Director)
- `etude/technique.md` : étude technique (Lead Programmer)
